# backlog-kit

Generado por `scripts/build-plugin.mjs` desde las plantillas de backlog-kit: no se edita a mano.

Instalación: `/plugin marketplace add juanmalonso/backlog-kit` y `/plugin install backlog-kit@backlog-kit`. El proyecto necesita el `.pm/` y los scripts de backlog-kit (`npx github:juanmalonso/backlog-kit init --claude plugin`). Las skills usan los nombres de estado del preset en español; si `.pm/config.json` los renombra, los scripts y el MCP usan los del config.

# backlog-kit-en

Generated by `scripts/build-plugin.mjs` from backlog-kit's templates: do not edit by hand.

Install: `/plugin marketplace add juanmalonso/backlog-kit` and `/plugin install backlog-kit-en@backlog-kit`. The project needs backlog-kit's `.pm/` and scripts (`npx github:juanmalonso/backlog-kit init --lang en --claude plugin`). Skills use the English preset status names; if `.pm/config.json` renames them, the scripts and the MCP use the configured names.
